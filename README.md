# Draftline

Dependency-free, local-first 2D CAD editor built with plain HTML, CSS, JavaScript, and a WebGPU-first renderer, with a Canvas 2D fallback.

The complete source, DXF samples, tests, and documentation are being imported from the Draftline source distribution created in this conversation.

The planned GitHub Pages URL is https://wieslawsoltes.github.io/Draftline/.
